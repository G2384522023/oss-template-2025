# [コミットメッセージ]

## 説明
コミットメッセージとは、Gitでコードの変更を保存する際に「何を・なぜ変更したのか」を記録するための文章です。
単なるメモではなく、後から作業内容を振り返ったり、他の開発者が変更意図を理解したりするために重要な役割を持っています。

特にチーム開発では、曖昧なコミットメッセージが原因で以下のような問題が発生することがあります。

・どのコードがどのバグ修正に対応しているのか分からない

・作業の重複や修正漏れが起きる

・レビューが進まず開発が遅れる

そのため、短くても内容が伝わるように書くことが求められます。
